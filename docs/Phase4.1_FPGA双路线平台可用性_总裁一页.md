## 0. Phase4.1 的意义（先读这节）

Phase4.1 **不是**再刷一个 MNIST 准确率，而是在长线（Phase8 / 定 BOM / 更大网）之前，用**真链路 + 真板资源**回答：

> **平台行不行？在什么条件下行？哪条路会白搞？**

三块账必须分开，不能用一块绿冒充关口关闭：

| 账 | 问的是什么 | 今日答案（阶段） |
|----|------------|------------------|
| **边缘主链** | Atlas 整网推理 + 延迟尺子 | G-LAT 复用连接已过尺子（PR#13）；**≠** 愿景了结 |
| **R-A 加速** | FPGA 只扛切出去的一块，工具链/板上通不通 | **单神经元 PL 通**；整层 256 入链仍待 |
| **R-B 整网** | 整网能不能「并行铺」进现板；若不能，替代条件是什么 | **并行阵列 LUT 墙已立**；若坚持整网 → 必须走**分时复用**或更大器件（另立项） |

**资源名词（人话）**——报利用率时会出现：

| 名 | 像什么 | 本闸主要卡谁 |
|----|--------|--------------|
| **LUT** | 逻辑工位 | **并行整网撞的是它**（单核≈379，×256≈97k > Z2 的 53k） |
| **FF** | 小状态货架 | 一般比 LUT 富余 |
| **BRAM** | 片上库房 | 权重/膜电位；本网~20 万突触 int16 往往不是第一墙 |
| **DSP** | 专用乘法冲床 | 当前单核 LIF 综合用了 0 个 |

**并行 vs 分时（R-B 核心收获）**

- **并行**：每个神经元一套 LIF 计算器同时算 → 快，但 LUT×N，Z2 上 **N≈256 不够**。  
- **分时**：一套（或很少）计算器轮流算 N 个神经元 → LUT 够，但要调度 RTL + 存储通路，**尚未实现**；资源够 ≠ 已经做了。

→ 这就是 Phase4.1 该交的账：**通 / 不通 / 在什么条件下通**，避免长线白搞。

## 1. 两条路（截至今日）

| 路线 | 平台可用？ | 证据 | 人话 |
|------|------------|------|------|
| **R-A 加速（M-lif）** | **单算子 + 向量化入链（分时）可用** | `fpga_ra_mlif_*_gate.json` + overlay | 单核 PL PASS；**向量化入链** N=20：与 host pred **100% 一致**、标签 acc **95%**；lif1 板上≈**923ms/样本**（MMIO 分时，远逊 G-LAT）。**≠** Atlas 以太网入链；**≠** 并行 RTL；**≠** 关口关闭。 |

## 2. 建议主路径（供你拍板，非自动定 BOM）

1. **近端可行**：以 **Atlas 整网** 为推理主链；FPGA 保留则走 **R-A**（下一步：向量化 / 真入链延迟——不是再赌 Z2 并行整网）。  
2. **勿押**「Z2 上并行整网」——LUT 墙已立；若要 FPGA 整网，先立项**分时复用**或换更大器件。  
3. **Phase8**：双路线已有可呈结论；是否解除 F2 → **请你一句书面确认**（默认仍不开）。
