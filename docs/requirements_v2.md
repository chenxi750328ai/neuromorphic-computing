## 3. 技术路线深化（Phase8 具体化，非替换现有基线）

### 3.1 v1（现网）vs v2 新增候选（并存，非替换）

| 项 | v1（现网 · 不变） | v2 新增候选（Phase8） |
|----|----|------|
| 学习方式 | 监督反传（BPTT-surrogate） | STDP + 稳态可塑性（无监督在线） |
| 收敛加速 | 无（依赖梯度） | 弱引导种群进化（目标函数引导 + 动态变异率 + 反馈闭环） |
| 验收基线 | MNIST test acc ≥90%（已达 96.97%） | **不单独设新及格线**；须在优势验证阶梯七件套上与 v1 基线**逐条对照**，含更差列 |
| 硬件落地 | Atlas OM 推理 + FPGA LIF 推理核（已闭环） | STDP 权重更新算子上 PL（**新增台阶，未开始**） |

详细技术设计见 [NEURO-V1-架构设计说明书.md](./NEURO-V1-架构设计说明书.md) §2–3。

### 3.2 明确排除项（v2 不做，避免范围膨胀）

- **不**在 v2 中重新验收 Phase1–4.1 已过的项（不重复造 TR1）。
- **不**把研究报告中的「100代/周」「进化提速30倍」等**理论推导数字**当作本项目验收指标（架构说明书 §2.3 已强调，此处重申）。
- **不**在 Phase4.1 主链未稳（含 G-LAT 攻关中）时启动 Phase8 工程开发（人签已过，但链路尺子未过；继承 GWT「不开」纪律精神）。
- **不**把「静默突触扩容 / 联邦蒸馏 / 车规规则兜底」纳入 Phase8 首版（单 AG；见 2026-07-25 摄入笔记 Out of scope）。
- **不**假设纯 STDP 自带任务语义——外部材料与 Neuron 级共识均指出**只会聚类**；任务能力依赖读出层 + 弱引导（V-H2）。

## 3.3 价值假设与止损判据（BON 业务评审补 · 2026-07-24）

> **背书缺口**：BON 业务内容评审（见 [TR1v2](./TR1v2_技术路线深化评审_总裁评审.md) §7）指出，v2 草案此前只回答了「怎么做才合规」，没回答「为什么值得做、赌的是什么、什么时候该停」。本节补上。

### 我们在赌什么（价值假设，须可证伪）

现床已实测：US-ACC 更差（96.97% vs 98.10%）、US-TR 更差（训练 ~3× 慢）、US-EN 更差（单位推理能耗 ≈×4.5）、US-SL 更差（开放域）。**类脑「更准/更快/更省」的原始卖点在同构稠密任务上没有成立**（优势验证阶梯 §2.2/§3.1）。

Phase8 追加投入 STDP+弱引导进化，赌的**不是**「换个学习规则就能翻盘同构任务」，而是狭义假设：

| 假设 ID | 赌的是什么 | 若成立 | 若不成立 |
|---------|------------|--------|----------|
| **V-H1** | 在**事件驱动/强稀疏输入**场景（非稠密 MNIST），STDP 在线学习的 US-EN/US-IDLE 表现优于「反传+跳帧 ANN」 | Phase8 才有继续投入的理由 | 应止损，转向其他方向或降级为纯学术记录 |
| **V-H2** | 弱引导种群进化能让 STDP 收敛速度/稳定性**优于纯 STDP**（不要求超过反传） | 弱引导机制本身有价值，可留作方法论资产 | 弱引导层可砍，只留 STDP+稳态可塑性最小实现 |

**不赌**：不赌 STDP 在 MNIST 类同构稠密任务上反超监督基线（现有证据方向相反，继续押注不诚实）。

### 止损判据（kill criteria，提前写清楚，不是失败后再找理由）

| 检查点 | 条件 | 动作 |
|--------|------|------|
| K1 · 最小任务不收敛 | 32 维二进制序列任务上，STDP+稳态可塑性经合理调参（见架构说明书 §2 补充）**跑不出稳定收敛**（放电率不落入 5–15Hz 带，或读出精度上不去） | **立即止损**：Phase8 降级为文献综述存档，不再派工 |
| K2 · V-H1 证伪 | 现床对照「STDP 在线学习」vs「跳帧/侦测触发 ANN」，US-EN/US-IDLE **未见优于**对照方案 | 止损：不追加硬件投入（FPGA 学习算子上 PL 暂停），仅保留仿真侧记录 |
| K3 · 资源超支 | 单 AG 排期下，最小端到端路径（见架构说明书 §6 补充 3）预计超过 **1 个月**仍未打通 GPU 仿真侧 | 重新评估，不无限期占用陈正共带宽 |

**诚实声明**：本节的存在本身即回应"批准 Phase8 会不会让'项目何时创造商业价值'更模糊"——答案是**会**，Phase8 是纯技术验证探索，**不承担、不承诺**任何商业化时点；若 K1/K2 触发，止损后不重新包装成"阶段性成果"对外宣讲。

## 4. 12 个月节奏对照（诚实差距，非照抄报告）

报告建议节奏（从零起步）：2 月算法验证 + 1 月 FPGA 移植 + 3 月产品原型 + 3 月商用验证 + 3 月标准化 = 12 月。

**本项目实际情况**：

| 差异点 | 说明 |
|--------|------|
| 起点不同 | 本项目已用 ~2.5 个月完成「算法验证 + FPGA 移植」阶段的**监督学习版本**（Phase1–4 v0），报告节奏针对的是「赫布/STDP 版本」从零开始，**不能直接复用已用月数** |
| 团队规模不同 | 报告假设 5 人团队（2 算法+1 硬件+1 产品+1 商业化）；本项目为 **陈正共单 AG + 总裁裁决**，节奏须按实际产能重估，不承诺报告中的月度节点 |
| 商用前提不同 | 报告的「首笔订单/12月商业化」以真实客户拓展为前提；本项目当前**零收入、零客户接触**，**Phase8 定位为纯技术验证，不进入任何可预见的商业化排期**（不是「不承诺12个月」这种留尾巴措辞——是明确不谈商业化，直到 §3.3 的 V-H1/V-H2 假设被验证） |

**建议**：Phase8 若批准，按**技术验证优先**排期，不套用报告的商业化月度表；具体排期待 Phase4.1 关单后另开 WO 细化。

**稀释效应，正面承认（不回避）**：批准 Phase8 不会让「本项目何时创造商业价值」这个问题更清晰——**只会更远**。现网监督式 SNN/ANN 已是相对成熟的路线，STDP+弱引导进化比现网离商业化更远（更偏基础研究）。批准 Phase8 的净效果是新增一条技术探索支线，**不是**加速商业化。若总裁的优先项是「尽快看到商业价值」，本节结论是：**不批准 Phase8 更符合该优先项**；批准的唯一理由应是「技术方向本身值得探索留档」，不应包装成「离赚钱更近了」。

## 5. 候选应用场景（探索方向，非范围锁定，含 PL 优先级判断）

继承 [愿景方案_平台映射与规格_V0.md](./愿景方案_平台映射与规格_V0.md) 「路线不预先唯一规定」的既有原则，报告提出的场景仅作为**候选方向**登记，不锁定。**BON 业务评审指出此前只是照抄报告场景清单、无优先级、且未处理与项目自有结论的矛盾**——本节补 PL 推荐排序：

| 优先级 | 候选场景 | 报告理由 | 本项目现状 | PL 判断 |
|--------|----------|----------|------------|---------|
| **P1（建议先做）** | 序列识别（32维二进制等） | STDP 最小验证任务 | 无代码 | 与 §3.3 V-H1/V-H2 假设直接对齐，**用于验证收敛性/止损判据 K1**，不是业务场景，是技术验证载体 |
| **P2（有条件候选）** | 工业边缘控制（贴膜机等） | README 已提及为可选场景 | 无代码/数据 | 若 V-H1（事件驱动/强稀疏场景 US-EN 优于跳帧 ANN）成立，此场景才有意义；**先过 V-H1 再谈** |
| **P3（低优先级）** | 机器人避障 | 相位序列 + 异步稀疏实时决策 | 无代码/数据 | 同 P2，依赖 V-H1；且需要真实传感器/执行器闭环，资源门槛高于本项目单 AG 现状 |
| **P4（不推荐作为 Phase8 早期目标，且与项目自有结论矛盾）** | 类脑写 PPT | 小样本联想记忆 + 风格适配 | 无代码/数据 | ⚠️ **与本项目 [优势验证阶梯](./优势验证阶梯与专用硬件规格_V1.md) US-SL 结论矛盾**：该文档明确「开放域远弱于 LLM」，写 PPT 恰是开放域生成任务，是 SNN/STDP 最差适配的方向之一。列为候选仅为忠实转述报告，**PL 不推荐作为 Phase8 任何阶段的验证场景** |

**排序理由**：P1 是纯技术验证（无需真实场景数据，可用于 K1/V-H1 判据），P2/P3 依赖 V-H1 先被验证才有意义，P4 与项目自身已有证据相悖，列入候选但明确不推荐。

### 优先级正面回答（当下最该做的是 Phase4.1 还是 Phase8？）

**答案：Phase4.1**。§8/§10 人签、PR#12 合入、TR2 签字是当前唯一处于「机尽等人」状态的关键路径；Phase8 是**新方向探索**，其价值假设（§3.3）尚未验证。本文档与 [TR1v2](./TR1v2_技术路线深化评审_总裁评审.md) 的存在**本身就是一次注意力支出**——总裁若只有零碎时间，**应优先处理 Phase4.1 的 4 个签字项**，Phase8 评审可以留到 Phase4.1 关单后一起批，不需要单独抽时间。C5/G5 的「不占执行带宽」承诺属实，但不等于「不占注意力」，本节不再用「并行不阻塞」的措辞模糊这一点。
