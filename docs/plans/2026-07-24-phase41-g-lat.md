## 测试用例是什么？（G-LAT 白话 · 总裁可读）

G-LAT **不是**「MNIST 准确率考试」，也 **不是** STDP/无监督学习测试。它是 Phase4.1 **链路够不够快** 的尺子。

| 项 | 内容 |
|----|------|
| **测什么** | WSL → Atlas **TCP 常驻 daemon(:9527)** → 回传预测，端到端延迟 |
| **模型** | 现网监督式 `MnistSNN` OM（反传训练好的推理图），**不是** STDP 在线学习 |
| **样本** | MNIST，至少 **N=100** 帧；先丢 **暖机 5** 帧；端到端 **>100ms** 的离群帧不进百分位 |
| **金标准** | 预测与本机 **ONNX Runtime (ORT)** 一致率 → 记入 **G-ACC**（与 G-LAT 同批跑） |
| **G-LAT 过线** | 稳态样本上：端到端 **p50 ≤ 5 ms** 且 **p95 ≤ 10 ms** |
| **脚本** | `phase4_distributed_bench.py --samples 100 --daemon-port 9527 [--daemon-reuse-conn] --vs-ort` → `phase4_spec_gate_report.py --gate` |
| **r1 实测** | G-ACC ✅；G-COMM ✅；G-LAT ❌（p50=**5.513** ms，超 0.513ms）→ **overall_ok=false** |
| **r2 实测** | `connection_reuse`：G-ACC ✅；G-COMM ✅；G-LAT ✅（p50=**3.501** / p95=**4.036**）→ **overall_ok=true**（exit 0） |
| **失败含义** | 「链路中位延迟略慢于暂定尺子」，**不是**模型算错，也**不是** Phase8/STDP 失败 |

同批其它门禁（便于对照）：

| ID | 人话 | r1 | r2 (`connection_reuse`) |
|----|------|-----|-------------------------|
| G-ACC | 和 ORT 是否一致（≥98%） | ✅ 100% | ✅ 100% |
| G-LAT | 够不够快（上表） | ❌ | ✅ |
| G-COMM | 分段账清楚、非常驻-SSH、别抖太狠 | ✅ | ✅ |
