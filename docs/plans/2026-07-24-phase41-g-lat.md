# Phase4.1 · G-LAT 攻关 Implementation Plan

> **For agentic workers:** 先完成本计划勾选；**禁止**未登记分支就开 PR。合 main 须 neuro-ci 绿 + 人审；**Agent 默认不 `gh pr merge`**（除非总裁当轮明示）。

**Goal:** 在现有 TCP daemon 链路上，使 **G-LAT** 稳态达标（p50≤5ms · p95≤10ms，口径同探索规格 §2），并留下可复现证据；**不**借此关闭 Phase4.1 关口。

## Tasks

### Task 0 · 建分支（计划已登记后）

- [ ] `git fetch origin && git checkout origin/main -b feature/phase4.1-g-lat`
- [ ] 确认 Atlas ping/ssh + daemon 可启（不通则本计划停在「阻塞：板网」，只交诊断，不开「已过关」PR）

### Task 1 · 同口径复测（先证伪「噪声」）

- [ ] 按探索规格：暖机 5、离群 >100ms 剔除、N≥100、vs ORT
- [ ] 连续跑 **≥3 轮** N=100（或 1×N=300），各出 `spec_gate_report_*.json`
- [ ] 记录：若 ≥2 轮 p50≤5 → 归因为噪声/负载，PR 以「复测达标」为主；若稳定 >5 → 进 Task 2

**验收：** 原始 bench JSON + 门禁报告落盘；`overall_ok` 真值如实。

### Task 2 · 分段归因 + 最小优化（仅当复测仍 FAIL）

候选（按侵入性从低到高，一次只改一类）：

1. bench 侧：减少每帧额外开销（多余 sleep/日志/重复 ORT 加载）
2. daemon 侧：预热 OM、固定线程/队列、payload 复用缓冲
3. 批推理：G-SCN 允许 1～8 张/批——若用 batch，须在报告注明口径，**不得**用均摊掩盖单张 p50

- [ ] 改前写清假说一行；改后同 Task 1 口径重测
- [ ] 若仍 FAIL：在 PR 中给「差额与下一假说」，**不**改阈值凑绿

**验收：** 至少一份前后对照表（p50/p95/comm 分段）。

### Task 3 · 文档与看板

- [ ] 探索规格 §4 表追加一行（日期、拓扑、G-*、结论资格=可填表·非关口定稿）
- [ ] 每日计划 / daily_progress 记账
- [ ] milestones focus 保持「G-LAT」直到证据更新

### Task 4 · 开 PR（Summary 模板强制）

```markdown
- [ ] phase4_spec_gate_report.py --gate（写明 exit code 期望）
- [ ] neuro-ci qa
```

| 维度 | 判定 | 说明 |
|------|------|------|
| **目标是否可测** | PASS | 阈值已钉死（5/10ms）；脚本已存在 |

| **分支/PR 是否先登记** | PASS | 见上表；纠正 PR#12 临时起 PR 的做法 |
| **失败是否诚实** | PASS | 允许 overall_ok=false 仍开 PR（交证据），禁止改尺子 |
| **风险：板不通** | 已标阻塞 | Task 0 失败则只交诊断 |
| **风险：用 batch 造假绿** | 已禁 | 均摊不得替代单张 p50 宣称 |

| **缺什么仍未设计** | 已知 | 具体优化补丁待 Task 1 归因后再写；避免空改 daemon |
| **是否可开工** | **有条件 GO** | Task 0 板网通 → 开工 Task 1；不通 → 停 |

**自评结论：** 计划可执行；**现在还不应开 PR**。下一动作 = 建 `feature/phase4.1-g-lat` + Task 1 复测。
