### 1.1 训练 / 推理软件栈

```text

```

| 层 | 现网实现 | 证据 |
|----|----------|------|
| 网络 | `MnistSNN`（2 层 × 25 tick LIF）· `MnistANN` 对照 | Phase1 96.97% · Phase2 98.10% |

## 2. 拟纳入架构：赫布在线学习 + 弱引导种群进化（Phase8 候选实现）

> 本节内容源自行业研究报告《类脑脉冲网络技术路线、验证体系与 EDA 工具选型》与《赫布理论后续研究及 12 个月落地可行性分析》，是**候选架构**，未落地代码，**未占用现有 Phase4.1 人力**。

### 2.1 核心命题：从「训练-冻结」到「推理即学习」

| 维度 | 现网（监督反传） | 拟纳入（赫布在线学习） |
|------|------------------|------------------------|
| 学习信号 | 全局梯度（需损失函数、需标签） | 局部时序相关性（无监督，无需全局梯度） |
| 学习/推理关系 | 训练与推理割裂（两段式） | **同步**：感知的同时更新权重（"思考即学习"）|
| 硬件适配性 | 依赖同步 SIMD（GPU）反传，异步硬件需近似 | 天然适配异步事件驱动硬件（局部更新、无需全局同步） |
| 已知短板 | 需要大量标注数据 | 纯 STDP 收敛慢、易陷局部最优（见 §2.3 弱引导） |

### 2.2 STDP：赫布规则的可工程化量化

```text
突触前脉冲早于突触后脉冲（Δt ∈ +10~20ms） → LTP（增强）
突触前脉冲晚于突触后脉冲                   → LTD（减弱）
```

- 局部、无监督、无需全局梯度，天然适配在线流式学习与异步硬件。
- 本项目候选实现：8 位定点动态放电阈值（0.2~0.7）；仅更新局部半径 5 邻域连接；步长随机 ±10%。
- 必备配套：**稳态可塑性**（Homeostatic Synaptic Plasticity）——负反馈机制，将神经元放电率维持在 5–15Hz 合理区间，抑制 STDP 正反馈失控（长期运行下的神经元静默/脉冲雪崩/活动失衡）。STDP 若单独使用**不构成完整学习规则**，本项目基线定为 **STDP + 稳态可塑性**，不单用 STDP。

### 2.3 弱引导种群进化框架（补 STDP 收敛慢的短板）

| 步骤 | 逻辑 | 与自然进化的区别 |
|------|------|------------------|
| ① 目标函数引导 | 双目标（学习步数最小化 + 算力消耗最低化）筛选种群 | 自然进化无目标、随机变异占比 99%+ 无效 |
| ② 变异概率引导 | 动态变异概率（前期高/后期低），保多样性→保收敛 | 自然进化变异概率固定，收敛慢 |
| ③ 反馈迭代引导 | 每 N 代按赫布学习实时反馈调整目标函数权重 | 自然进化反馈周期以万年计 |
| ④ 交叉重组 + 小规模变异 | 子代继承 STDP 在线学习能力（个体持续学习 + 种群演化双层优化） | — |

**工程纪律（不炒概念）**：报告原文给出的「100 代/周」「进化速度提升 30 倍」「与地球 35 亿年自然进化 PK」等数字是**理论推导 + 文献外推**，本项目引用其**方法论**（目标函数引导/动态变异率/反馈闭环），**不直接引用其量化倍数作为本项目验收指标**——本项目验收仍以 §4 现床实测为准，不得用他人报告数字冒充本项目数据。

### 2.4 与 GWT / 现网 SNN 的接口关系（避免推倒重来，且避免三轨混谈）

> **BON 架构评审纠错（2026-07-24）**：此前版本的示意图把「现网 MnistSNN / 陈东 OEDA / 弱引导进化」三条线用箭头汇入同一个 STDP 头，视觉上做了 §1.4 明令禁止的"合并叙事"。以下改为**分层图**，纵轴=粒度，横轴=学习信号，三轨各自落格，不汇流。

```text
                    学习信号 →
                    全局梯度(监督)      局部时序相关(无监督)      群体层选择
粒度 ↓
突触/神经元层   [现网 MnistSNN]      [Phase8 候选：STDP+稳态可塑性]  [弱引导种群进化
                反传训练·已闭环        本文档§2.2·未落地代码          （作用于STDP个体的
                （唯一现网基线）                                      收敛速度，见§2.3）]

episode/语言层                                                  [陈东 OEDA 进化
                                                                  语言阶段L0→L3
                                                                  与本行完全独立]
```

**读图规则**：
1. 「现网 MnistSNN」永远只在"突触层 × 全局梯度"格，**不因 Phase8 立项而挪格**。
2. 「Phase8 候选」落在"突触层 × 局部时序相关"格，**弱引导进化是它的加速器**（同一格内的辅助机制），不是并列第三轨。
3. 「陈东 OEDA」独占"episode/语言层"整行，与上面两格**无箭头连接**——这是本次纠错的核心：此前的图画了箭头，是错的。
4. 若 Phase8 落地，产出的是**新增一个模型对象**（如 `MnistSNN_STDP`），与现网 `MnistSNN`（反传）**并存对照（A/B）**，不修改、不替换现网基线的代码路径。

- **不替换** Phase1–3 已验收的监督基线（那是精度/性能门槛的对照锚点，见优势验证阶梯 US-ACC/US-TR）。
- Phase8 落地时须**同时报告**：反传基线 vs STDP+弱引导在线学习基线，在优势验证阶梯七件套上**逐条填表**（含更差列），不得只报在线学习的优点。

### 2.5 落地绑定规格（BON 架构评审补 · 此前缺失，导致"方法论≠可写代码的规格"）

> **缺口**：此前 §2.2 只给了阈值/邻域半径/变异率等参数，缺了"具体加在哪个网络、时间单位怎么对齐、权重怎么量化、无监督怎么打分"四项——这四项不补，任何 Agent 都无法直接开工。以下补齐，仍是**规格**，不是代码。

| 项 | 规格 |
|----|------|
| **拓扑绑定** | 不直接在 `MnistSNN`（2 层×25 tick，Phase1–3 现网基线）上加 STDP 头。**新建独立最小拓扑** `stdp_seq_net`（单层，规模对齐 32 维二进制序列任务，神经元数待仿真调参，初始建议 32–64），与现网拓扑物理隔离，避免"改现网代码"的误读 |
| **tick↔ms 映射** | 现网 tick 展开无固定物理时长；STDP 候选拓扑**须显式定义** 1 tick = N ms（初始建议 N=1，即 STDP 窗口 Δt∈+10~20 tick），且此映射为**仿真参数**，随收敛效果可调，写入 `metrics.json` 的 `tick_ms` 字段，不得隐式假设。**外部文献摄入（2026-07-25）补充风险**：时序对齐误差过大时因果可塑性易失效（文献称 ~3ms 量级）；详细设计须论证仿真 tick 与目标物理窗的误差预算，**不得**在 GPU 批量仿真里假装已具备物理异步保真 |
| **Δw 量化规则** | 权重 Δw 用**浮点仿真**（GPU 阶段，L1）；进入 L2/L3（EDA/FPGA）时定点化为 8 位（与 §2.2 放电阈值同精度），量化误差须在 L2 仿真中与浮点版对比留档（`stdp_quant_error.json`），**不得**跳过量化误差记录直接烧板 |
| **无监督读出/打分机制** | STDP 本身不产生标签。候选方案：脉冲计数打分（spike-count labeling）——训练后对每类样本统计各神经元平均放电率，选峰值神经元为该类"代表"，推理时按放电计数匹配代表神经元定类。**这是 STDP 类工作最容易翻车的环节，缺此项 = 无法评估收敛，Phase8 若无此模块视为未开工**。外部材料重申：**纯 STDP 仅聚类、无任务语义**——与本行一致，非新范围 |
| **首版明确不做（2026-07-25 摄入）** | 静默突触动态扩容、云端联邦蒸馏补容、车规「规则硬兜底」量产架构——理论可研，**单 AG 首版 Out of scope**；见 [摄入笔记](./research/STDP无监督优化目标_文献摄入_20260725.md) |

**结论**：Phase8 若被批准派工，第一个交付物须是**含上述绑定项的详细设计文档**（非本节草案深度），而非直接写训练脚本。

## 3. 硬件路线分层与工具链（架构侧选型说明）

### 3.1 GPU / FPGA / ASIC 层级取舍

| 层级 | 角色 | 本项目当前状态 |
|------|------|----------------|
| **GPU（4090）** | 离线算法预研/批量仿真；同步 SIMD，只能软件模拟事件驱动 | ✅ 训练/金标准/编排在用 |
| **FPGA（PYNQ-Z2）** | 一期最优落地载体：异步脉冲逻辑重构、实时硬件闭环、在线学习验证候选 | ✅ E4 推理算子已闭环；**学习算子未上 PL**（§2.4 缺口） |
| **神经形态 ASIC** | 中长期量产终极方案：原生异步事件驱动、存算紧耦合、超低功耗 | ❌ 未启动；须先在 FPGA 充分验证架构稳定 |

标准演进路径：**GPU 算法预研 → EDA 逻辑验证 → FPGA 样机落地 → 成熟后 ASIC 量产**。本项目当前处于「GPU 预研 + FPGA 样机（推理段）」，学习算子的 EDA/FPGA 验证**未开始**。

### 3.2 三级技术验证流水线（GPU-EDA-FPGA）

| 级 | 内容 | 本项目现状 | 工具 |
|----|------|-----------|------|
| **L1 GPU 算法仿真** | SNN 搭建、STDP 调试、种群进化迭代、超参遍历 | 现网 PyTorch 训练已用；STDP/进化仿真**未开发** | PyTorch（已用）、SpikingJelly（对照，见 [cdt_v1_stack_alignment.md](./cdt_v1_stack_alignment.md)） |
| **L2 EDA-RTL 仿真** | 定点数字逻辑、时序前仿、脉冲路由/STDP 权重更新时序仲裁校验 | LIF 推理核已过（`fpga_lif_rtl_sim.py`）；**STDP 权重更新时序仲裁未做** | Verilator（批量仿真）、Icarus Verilog + GTKWave（小规模调试）、Yosys（综合预校验） |
| **L3 FPGA 实物** | 硬件在环（HIL），真实传感器/执行器闭环 | LIF 推理核已烧 PL（`chain_full_pl_ok=true`）；**学习算子未烧 PL** | Vivado 2023.2（综合）、PYNQ sudo Overlay |

**结论（架构侧，不改判据）**：现有 E4 闭环证明的是「LIF **推理**算子可上 PL」，若要纳入 §2 在线学习架构，需**新增**「STDP 权重更新算子」走完 L1→L2→L3，**当前未做**，不得混同为「学习算子也已上板」。

### 3.3 EDA 工具链选型（研发配套，非产品 BOM）

| 类别 | 工具 | 用途 | 成本 |
|------|------|------|------|
| 主力（一期） | Verilator | 高性能 Verilog 仿真，支持批量加速，适配 SNN 大规模模块迭代 | 永久免费开源 |
| 主力（一期） | Icarus Verilog + GTKWave | 小规模模块快速调试、脉冲时序观测 | 永久免费开源 |
| 主力（一期） | Yosys | RTL 综合预校验、转门级网表 | 永久免费开源 |
| 外围 | 立创 EDA（LCEDA） | FPGA 外围硬件电路 PCB 设计 | 永久免费（国产） |
| 备用（后期） | 芯华章 GalaxSim / 合见工软 UVS / 泛联新安 VShark | 顶层时序后仿、大规模验收、静态检查 | 国产商业 EDA，评估试用 |
| 现用 | Vivado 2023.2 | FPGA 综合、比特流生成（E4 已用） | AMD 官方（已装） |

**风险说明**：开源工具链可满足 FPGA 原型开发，**不支持 ASIC 级 Signoff 签核**；若 Phase8 后续走向 ASIC 流片，须采购正式商业授权——现阶段不产生该成本。

## 4. 技术难点与攻坚方向（映射到本项目已知断点）

> 归纳自《类脑智能项目技术难点及攻坚方向补充》，按"是否已在本项目出现"分列，避免空谈。

**优先级原则（继承报告 + 本项目现状）**：聚焦影响 Phase4.1/Phase8 主链的难点（算法-硬件映射、鲁棒性），标准/人才等次要难点不占用当前带宽。

### 4.1 单人可行性与资源预算（BON 架构评审补 · 补充 3）

**问题**：§2.4 写「与反传训练并存对照（A/B），不替换现网基线」——对单 AG 而言，这句话若理解为「长期同时维护两套学习栈、且 L1→L3 三级都要双跑」，**不现实**，会导致排期无限拖延。本节把这一冲突显式化为架构决策，而非留在排期备注里。

**决策（降配，非取消 A/B 对照）**：

1. **A/B 对照的范围收窄为仿真侧（L1 GPU）**，**不要求硬件侧（L2/L3）同时双栈**。理由：A/B 对照的目的是"诚实报告优劣"（继承 Stage B 纪律），这一目的在 L1 仿真侧已可达成；硬件侧双栈维护成本对单 AG 不成比例。
2. **单人排期须先选定一条最小端到端路径，不铺满 L1→L3 × A/B 全矩阵**：建议路径 = 「32 维序列任务 → STDP+稳态可塑性仿真（L1）→ 收敛判据达标后才进 L2」，即**先把 L1 一条线走完，再决定是否值得投入 L2/L3**（对应 §3.3 K3 止损判据：L1 超 1 个月未通须重新评估，不进入 L2）。
3. **FPGA 资源增量估算（决策依据）**：现网 LIF 推理核已实测 `379 LUT / 0 DSP / 0 BRAM`（[phase4_fpga_toolchain_V0.md](./phase4_fpga_toolchain_V0.md) §4）。STDP 权重更新算子**新增**：(a) 权重存储需 BRAM（现推理核 0 BRAM，STDP 至少需 1 块 BRAM 存权重矩阵，PYNQ-Z2 共 280 块，非瓶颈但非零）；(b) 时序仲裁逻辑预估 LUT 消耗与推理核同量级（**待 L2 仿真后用实测替换本估算，此处只是决策所需的量级判断，不是最终验收数字**）。结论：资源本身不构成 PYNQ-Z2 上的硬瓶颈，**真正瓶颈是单 AG 的时间预算**，因此上述路径收窄以时间止损为主。
