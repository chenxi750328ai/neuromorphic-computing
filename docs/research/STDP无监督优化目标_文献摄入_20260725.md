## 2. 对本项目的影响裁定

### 2.1 影响 Phase4.1 / G-LAT？

**几乎无直接影响。**  
G-LAT 测的是 **监督式 MnistSNN OM 在 Atlas TCP daemon 上的端到端延迟**，与 STDP 无监督训练无关。  
本材料**不改变** G-LAT 阈值、测试脚本或关口纪律。

### 2.2 影响 Phase8 / TR1v2？

| 影响 | 动作 |
|------|------|
| 强化「STDP+稳态+弱引导」选型理由 | 更新 `requirements_v2` 输入表 + 架构说明书修订记录 |
| 强化「纯 STDP 无任务语义」→ 读出层必做 | 已在 §2.5；本摄入记为外部背书，**不新开范围** |

| 静默突触 / 联邦蒸馏 / 车规规则兜底 | **登记为 Phase8+ 候选项**；单 AG 首版 **Out of scope** |
