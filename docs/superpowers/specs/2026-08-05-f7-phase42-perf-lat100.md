# Phase4.2 · F7 整网性能攻关 spec（WO-DEV-NEURO-F7-PERF）

> **作者**：陈正飞 · 2026-08-05  
> **基线**：≈306 s/张（MMIO time-mux）· gate `fpga_rb_fullnet_pl_fc_gate.json`  
> **目标**：P4.2-LAT ≤ **100 ms/张** · ACC 不回退

## 根因

| 层 | 问题 | 占比 |
|----|------|------|
| PS↔PL | 每 MAC/LIF 一次 AXI-Lite 往返 | ~98% 墙钟 |
| 调度 | 6650 次/张细粒度 kick | 调用次数爆炸 |
| 数据 | 权重未 DMA 流式 | 重复 MMIO 写 |

## 本 WO 已落刀（software-only，同 overlay）

1. `scripts/phase4_fpga_f7_mmio_fast.py` — 紧轮询 + 本地 write/read 引用  
2. `scripts/phase4_fpga_rb_fullnet_pl_fc_board.py` — 预绑定权重行  
3. `scripts/phase4_fpga_rb_fullnet_pl_fc_perf.py` — 机读 perf JSON + `--gate`  
4. `fpga/rtl/fullnet_tick_scheduler.v` — PL tick 调度 RTL 草案（待 Vivado v2）

**预期**：软件侧仅边际改善（Python/轮询）；**达不到 100 ms** 除非 overlay v2（DMA + PL scheduler）。
